# Café Levant Website

## Overview

The Café Levant website is a modern, responsive web platform designed to showcase the café’s offerings, atmosphere, and services. It provides customers with easy access to the menu, location, reviews, and online ordering options.

## About Café Levant

Café Levant is a cozy coffee shop located at Rubis Kenyatta Avenue Service Station, Jomo Kenyatta Avenue, Mombasa, Kenya. It is known for its quality coffee, burgers, and a calm, welcoming atmosphere. The café operates 24 hours a day and offers both dine-in and takeaway services.

## Features

* **Homepage:** Introduction, branding, and quick navigation
* **Menu Section:** Displays available items including coffee, burgers, and snacks
* **Reviews:** Highlights customer feedback and ratings (4.4/5)
* **Contact Page:** Includes location, phone number, and directions
* **Order Integration:** Link to external ordering platform (Glovo)
* **Responsive Design:** Optimized for mobile, tablet, and desktop
* **Modern UI/UX:** Clean layout with smooth navigation

## Installation & Setup

1. Clone or download the project files
2. Open the project folder
3. Launch `index.html` in your browser

## Usage

* Navigate through pages using the menu bar
* View menu items and café information
* Use the “Order Now” button to place orders via Glovo
* Access contact details and directions easily
